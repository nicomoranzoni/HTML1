Sección 1 — HTML

HTML define la estructura y el contenido de la página mediante etiquetas. La mayoría abren y cierran (<p>...</p>); algunas no llevan cierre (<img>, <meta>, <hr>).

Estructura básica del documento

El esqueleto mínimo de todo archivo .html. En VS Code se genera escribiendo ! + Tab (Emmet).

<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Título de la pestaña</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <!-- Contenido visible acá -->
  </body>
</html>
ParteQué hace
<!doctype html>Le dice al navegador que es HTML5.
<html lang="es">Raíz del documento; lang indica el idioma.
<head>Metadatos e info (no se ve en la página).
<meta charset="UTF-8">Codificación: que se vean bien tildes y ñ.
<meta name="viewport"...>Hace que la página se adapte al ancho del dispositivo (responsive).
<title>Texto de la pestaña del navegador.
<link>Vincula archivos externos (CSS, íconos, fuentes).
<body>Todo el contenido visible de la página.
Ojo: Emmet crea el archivo con lang="en". Cambialo a "es" si tu contenido está en español. Y si el CSS "no hace nada", lo primero a revisar es que el <link> exista y la ruta sea correcta.

Etiquetas de texto

Encabezados <h1> a <h6>

Seis niveles de título. <h1> es el más importante, <h6> el menos. Se eligen por jerarquía del contenido, NO por tamaño (el tamaño se ajusta con CSS).

<h1>Título principal</h1>
<h2>Subtítulo de sección</h2>
<h3>Subsección</h3>

Párrafos <p>

Bloques de texto. El navegador separa los párrafos con espacio vertical automáticamente.

<p>Este es un párrafo de texto.</p>
Regla clave: el nivel del encabezado indica importancia, no tamaño. Nunca uses un <h4> "porque se ve más chico"; eso se resuelve con font-size en CSS.

Listas

Ordenada <ol> (numerada)

Para elementos con orden (pasos de una receta, un ranking). Atributos: type (1, A, I) y start (desde qué número arranca).

<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
</ol>

Desordenada <ul> (viñetas)

Para elementos sin orden particular (ingredientes). Atributo type: disc, circle, square.

<ul>
  <li>Un ítem</li>
  <li>Otro ítem</li>
</ul>

Cada ítem va en un <li> (list item), siempre dentro de un <ol> o <ul>.

Enlaces <a>

Crean vínculos. El atributo href indica el destino; el texto entre las etiquetas es lo que ve y clickea el usuario.

<a href="https://google.com">Ir a Google</a>
Tipo / atributoQué hace
ExternoURL completa (ruta absoluta): href="https://..."
LocalA otro archivo tuyo (ruta relativa): href="inicio.html"
AnclaA una sección de la misma página: href="#servicios" salta al elemento con id="servicios"
target="_blank"Abre el enlace en una pestaña nueva.

Imágenes <img>

Inserta imágenes. No lleva etiqueta de cierre.

<img src="foto.jpg" alt="Descripción de la foto" width="400" />
AtributoQué hace
srcRuta de la imagen (obligatorio). Relativa al HTML.
altTexto alternativo (accesibilidad + SEO). Se muestra si la imagen no carga.
width / heightAncho / alto. Si ponés solo uno, mantiene la proporción.
Práctica moderna: mejor controlar el tamaño desde CSS (width en la regla) y no como atributo. Para responsive: max-width: 100% evita que la imagen se salga en pantallas chicas.

Tablas

Solo para datos tabulares (grillas de datos), nunca para maquetar.

<table>
  <tr>
    <th>Materia</th>
    <th>Nota</th>
  </tr>
  <tr>
    <td>Programación</td>
    <td>9</td>
  </tr>
</table>
EtiquetaQué es
<table>Contenedor de toda la tabla.
<tr>Una fila (table row).
<th>Celda de encabezado (título de columna, negrita).
<td>Celda de datos normal.
Regla de oro: todas las filas deben tener la misma cantidad de celdas. En CSS, border-collapse: collapse junta los bordes y deja la tabla prolija.

Formularios

Permiten al usuario ingresar datos. Todo va dentro de <form>, que es el contenedor único.

<form action="" method="POST">
  <div>
    <label for="email">Email</label>
    <input type="email" id="email" name="email" placeholder="tu@mail.com" />
  </div>
  <input type="submit" value="Enviar" />
</form>
Elemento / atributoQué hace
<form>Contenedor. action = a dónde van los datos; method = cómo (POST/GET).
<label for="x">Etiqueta del campo. El for debe coincidir con el id del input.
<input>Campo de entrada. type: text, email, password, number, checkbox, radio, submit.
idIdentifica el input (para el label y para CSS/JS). Único.
nameNombre de la variable que recibe el servidor.
placeholderTexto de ayuda gris dentro del campo.
Lo más importante: la relación label for ↔ input id deben coincidir exactamente. Al hacer clic en el label, el cursor salta al campo. Usá id/name sin tildes ni ñ.

Etiquetas semánticas y contenedores

Contenedores con significado. Se usan igual que un <div> pero le dicen al navegador y a los buscadores qué rol cumple cada zona.

EtiquetaZona que representa
<header>Cabecera (arriba: logo, título, menú).
<nav>Zona de navegación (menú de enlaces).
<main>Contenido principal (una sola vez por página).
<section>Sección temática del contenido.
<article>Contenido independiente (una nota, un post).
<footer>Pie de página.
<div>Contenedor genérico SIN significado. Comodín para agrupar y maquetar.

Bloque vs. línea

TipoComportamientoEjemplos
BloqueOcupan todo el ancho disponible; generan salto de línea.<div>, <p>, <h1>, <section>
LíneaOcupan solo el ancho de su contenido; no cortan línea.<span>, <a>, <img>
Recordatorio del profe: las etiquetas en línea van siempre dentro de etiquetas en bloque. Primero pensá QUÉ es el bloque (semántica), después cómo se VE (CSS).

Sección 2 — CSS

CSS define la apariencia: colores, tamaños, posiciones. Una regla se compone de un selector y sus declaraciones (propiedad: valor).

selector {
  propiedad: valor;
}

Cómo vincular CSS

FormaCómoUso
Externa (recomendada)<link rel="stylesheet" href="style.css"> en el headSepara contenido de diseño. La que usa el profe.
Interna<style>...</style> en el headPara una sola página.
En línea<p style="color:red">Casos muy puntuales. Evitar.

Fondos (backgrounds)

PropiedadQué haceValores útiles

background-repeatSi se repite en mosaicono-repeat, repeat

Combo típico para una imagen que cubra todo el fondo sin repetirse:

body {
  background-image: url("fondo.jpg");
  background-repeat: no-repeat;
  background-size: cover;
  background-position: center;
}
Ojo con las rutas: en CSS la ruta de url() es relativa al archivo .css, no al HTML. Distinto de <img> (contenido) vs background-image (decorativo).

Box Model

Todo elemento es una caja con cuatro capas, de adentro hacia afuera: contenido → padding → border → margin.

PropiedadQué esEjemplo
width / heightAncho / alto de la cajawidth: 80%;
paddingEspacio INTERNO (entre borde y contenido)padding: 1rem 2rem;
borderEl borde. Siempre lleva estiloborder: 2px solid #333;
marginEspacio EXTERNO (separa de otras cajas)margin: 2rem;
box-sizingCon border-box, padding y border se descuentan del widthbox-sizing: border-box;
border-radiusRedondea las esquinasborder-radius: 8px;

Trucos: margin: 0 auto; centra una caja horizontalmente. border necesita SÍ o SÍ el estilo (solid, dashed, dotted); sin él no aparece.

Padding con varios valores: padding: 10px 20px; = arriba/abajo, izq/der. Con 4 valores es en sentido horario: arriba, derecha, abajo, izquierda.

¿Padding o margin? ¿Quiero aire ADENTRO de la caja? → padding. ¿Quiero SEPARAR de otras? → margin. Poné box-sizing: border-box casi siempre: hace los tamaños predecibles.

Unidades

UnidadRelativa aNota
pxFija (absoluta)Para bordes finos o tamaños fijos.
remFuente del html (16px por defecto)La preferida. 1rem = 16px, 2rem = 32px.
emFuente del elemento padrePuede acumularse al anidar; el profe usa más rem.
%Tamaño del contenedor padreMuy usado para anchos.
vw1% del ancho de la ventana100vw = todo el ancho.
vh1% del alto de la ventana100vh = toda la altura de la pantalla.
Conversión px → rem: dividí por 16. 24px = 1.5rem, 40px = 2.5rem. Regla del profe: usar relativas siempre (rem, %) para que la página se adapte. Fijo (px) solo cuando no importa la flexibilidad. Para tamaños, usá una escala redonda: 0.5, 1, 1.5, 2, 3rem.

Flexbox

Sistema para acomodar elementos: ponerlos en fila/columna, alinearlos, distribuirlos. Funciona con la lógica contenedor padre → hijos directos. Se activa en el padre.

.contenedor {
  display: flex;
}

Con eso los hijos se ponen en fila. Las propiedades van en el contenedor:

PropiedadQué haceValores
flex-directionDirección de los hijosrow (default), column
justify-contentDistribución en el eje principal (horizontal si es row)flex-start, center, flex-end, space-between, space-around
align-itemsAlineación en el eje secundario (vertical si es row)stretch, center, flex-start, flex-end
gapEspacio entre los hijosgap: 1rem;

Patrón: header (logo a un lado, menú al otro)

header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Patrón: centrado perfecto (horizontal + vertical)

.contenedor {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}
Claves: display: flex va en el PADRE y controla a sus HIJOS DIRECTOS. justify-content = eje horizontal; align-items = eje vertical (cuando es row). Se puede anidar flex dentro de flex (ej. el nav dentro del header). Para centrar en vertical hace falta que el contenedor tenga altura (height: 100vh u otra).
